## Implementasi Soal Tes Junior Programmer   
- Mengambil data produk dari API yang di sediakan
- Menyimpan ke database dengan tabel:
  - **Produk** `(id_produk, nama_produk, harga, kategori_id, status_id)`  
  - **Kategori** `(id_kategori, nama_kategori)`  
  - **Status** `(id_status, nama_status)`  
- Menampilkan daftar produk yang disimpan  
- Menampilkan hanya produk dengan status **“bisa dijual”**  
- Fitur **CRUD** (Create, Read, Update, Delete) dengan validasi:
  - **Nama produk** wajib diisi  
  - **Harga** harus berupa angka  
- Konfirmasi saat menghapus data
